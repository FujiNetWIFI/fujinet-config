# font.txt -- the NES CONFIG's character set, drawn for this project in the
# manner of the Famicom's Family BASIC: 7x7 thin-stroke glyphs in the top-left
# of each 8x8 cell, a slashed zero, tile number = ASCII code. Lowercase is
# ours (Family BASIC has none); its descenders drop into the cell's blank 8th
# row. tools/mkfont.py turns this into the CHR-ROM (build/font.s).
#
# A block is a header line "= <char>" (or "= $hh" for a raw tile number,
# optionally followed by "plane N" -- the bitplane the dots go in, default 0,
# so plane 1 draws in palette colour 2) and up to 8 rows of up to 8 cells,
# '#' set and '.' clear. A row may also give a cell's palette colour, 1-3,
# for a tile that mixes colours. Tiles not given are blank. $80-$FF are
# generated: the reverse-video copies of $00-$7F that cc65's revers()
# selects. Only text is ever reversed, so $80-$9F (the copies of the frame
# and bar tiles) may be given here instead.
