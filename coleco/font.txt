# font.txt -- CONFIG's tiles, shared in form with the Master System CONFIG:
# drawn for this project in the manner of Phantasy Star's menus, white on
# black, capitals the full 8 rows tall with a 2-pixel left stem and 1-pixel
# strokes elsewhere, column 7 left blank between letters, thin 7-row digits.
# Lowercase is ours (Phantasy Star has none): an x-height of five rows on the
# capitals' baseline; the descender letters fold their tails into the cell's
# bottom row. tools/mkfont.py turns this into build/stage/font.inc.
#
# A block is a header line "= <char>" (or "= $hh" for a raw tile number,
# optionally followed by "colour N", which this platform ignores: colours go
# by tile group, disp.inc's COLOUR_TARGETS) and up to 8 rows of exactly 8
# cells, '#' set and '.' clear. Tile number = ASCII code from $20 up; tiles
# not given are blank. tools/mkfont.py moves the tiles below $20 to their
# places here.

# ---- window frame, cursor and sprite tiles ---------------------------------
#
# One corner and two edges make every window: tools/mkfont.py flips them for
# the other three corners and the bottom and right edges. The line is two
# pixels thick and sits one pixel in from the tile's edge.
